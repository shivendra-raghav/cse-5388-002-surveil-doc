Wasabi Cloud Storage Documentation

Introduction:
Wasabi Cloud Storage is a secure, affordable, and highly durable cloud storage service designed for businesses of all sizes. It provides a simple and reliable solution for storing and accessing data in the cloud. With Wasabi, you can store and retrieve an unlimited amount of data with no fees for egress or API requests.

Wasabi Cloud Storage Access Details:
To access your Wasabi Cloud Storage account, you will need to log in using your JohnDoe@example.com and <PASSWORD> at the Wasabi console (https://wasabi.com/console). Once logged in, you can view and manage your storage buckets, monitor usage, and configure access settings.

For programmatic access to your Wasabi Cloud Storage buckets, you will need to create an access key pair consisting of an <ACCESS_KEY> and a secret key. These keys will be used to authenticate your API requests. It is important to keep your secret key secure and never share it with unauthorized parties.

Here's an example of how you can use the access key pair with the AWS Command Line Interface (CLI) to list the contents of a Wasabi bucket:

```
aws --endpoint-url https://s3.wasabisys.com s3 ls s3://my-bucket-123 --no-sign-request --region us-east-1 --access-key-id=<ACCESS_KEY> --secret-access-key=your-secret-key
```

Data Immutability:
Wasabi Cloud Storage provides immutable data storage, which means that data stored in Wasabi cannot be modified or deleted for a specified period of time, known as the immutability period. This feature is particularly useful for organizations that need to comply with regulatory requirements or maintain data integrity for legal or compliance purposes.

To enable data immutability for a Wasabi bucket, you can set the immutability period during bucket creation or modify the existing bucket settings. Once the immutability period is set, objects stored in the bucket cannot be overwritten or deleted until the immutability period expires.

S3 Compatibility:
Wasabi Cloud Storage is designed to be fully compatible with the Amazon S3 API. This means that you can use the same tools and applications that you would use with Amazon S3 to interact with Wasabi Cloud Storage. Wasabi supports all S3 API operations, including PUT, GET, DELETE, LIST, and various bucket and object management operations.

This compatibility allows you to easily migrate your data and applications from Amazon S3 to Wasabi Cloud Storage or use Wasabi as a drop-in replacement for S3 in your existing applications and workflows.

Here's an example of how you can use the AWS CLI to upload a file to a Wasabi bucket:

```
aws --endpoint-url https://s3.wasabisys.com s3 cp /path/to/local/file s3://my-bucket-123/remote-file.txt --no-sign-request --region us-east-1 --access-key-id=<ACCESS_KEY> --secret-access-key=your-secret-key
```

Remember to replace `my-bucket-123`, `remote-file.txt`, `<ACCESS_KEY>`, and `your-secret-key` with your actual values.

For more information and detailed usage examples, please refer to the Wasabi Cloud Storage documentation at https://wasabi.com/documentation.

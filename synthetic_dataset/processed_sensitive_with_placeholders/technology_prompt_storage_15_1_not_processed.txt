# OVHcloud Object Storage Documentation

## Introduction

OVHcloud Object Storage is a highly scalable, reliable, and secure cloud storage service offered by OVHcloud. It allows you to store and manage large amounts of unstructured data, such as documents, images, videos, and backups, in a cost-effective and easily accessible manner.

This documentation will provide a comprehensive overview of the OVHcloud Object Storage service, including access details, versioning capabilities, and access logging features to help you effectively leverage this solution within your organization.

With the API access token, you can integrate OVHcloud Object Storage into your applications and automation workflows, allowing you to programmatically manage your storage resources.

## Versioning

OVHcloud Object Storage provides built-in versioning capabilities, which allow you to track and restore previous versions of your stored objects. This feature is particularly useful for protecting against accidental deletion or modifications, as well as for maintaining a comprehensive audit trail of changes.

**Enabling Versioning**
To enable versioning for a specific storage container:
1. Log in to the OVHcloud management console.
2. Navigate to the "Object Storage" section and select the container you wish to enable versioning for.
3. Click on the "Versioning" tab and toggle the versioning setting to "Enabled".
4. (Optional) Configure any additional versioning settings, such as the number of versions to retain or the versioning suspension behavior.
5. Save the changes to apply the versioning configuration.

**Viewing and Restoring Versions**
Once versioning is enabled, you can view and restore previous versions of your stored objects:
1. Navigate to the storage container and locate the object you wish to view versions for.
2. Click on the object to open the details view, then select the "Versions" tab.
3. This will display a list of all available versions for the object, including the version ID, modification date, and size.
4. To restore a previous version, simply click the "Restore" button next to the desired version.

Versioning provides an additional layer of data protection and allows you to quickly recover from accidental or malicious changes to your stored objects.

## Access Logs

OVHcloud Object Storage also provides comprehensive access logging capabilities, which track all interactions with your storage resources. These logs can be valuable for security monitoring, compliance reporting, and troubleshooting purposes.

**Enabling Access Logging**
To enable access logging for a specific storage container:
1. Log in to the OVHcloud management console.
2. Navigate to the "Object Storage" section and select the container you wish to enable logging for.
3. Click on the "Logs" tab and toggle the logging setting to "Enabled".
4. (Optional) Configure the log file prefix, log retention period, and other advanced settings as needed.
5. Save the changes to apply the logging configuration.

**Accessing and Analyzing Logs**
Once logging is enabled, you can access the generated log files in the following ways:
1. Through the OVHcloud management console: Navigate to the "Object Storage" section, select the container, and click on the "Logs" tab to view and download the available log files.
2. Using the OVHcloud API: Leverage the API's logging-related endpoints to programmatically retrieve and analyze the log data. You will need to use the <ACCESS_TOKEN> generated earlier to authenticate your API requests.
3. Integrating with a third-party log management solution: Export the log files to a tool like Splunk, Elasticsearch, or Sumo Logic for advanced analysis and reporting.

The access logs provide a detailed record of all read, write, and delete operations performed on your OVHcloud Object Storage resources, including information such as the requesting user, the action taken, the object accessed, and the timestamp. This data can be invaluable for security monitoring, compliance auditing, and troubleshooting purposes.

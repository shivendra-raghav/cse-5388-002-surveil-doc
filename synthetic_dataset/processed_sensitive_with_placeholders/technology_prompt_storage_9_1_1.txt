Oracle Cloud Storage Documentation

Introduction
Oracle Cloud Storage is a highly durable and secure object storage service that enables organizations to store an unlimited amount of data. This documentation provides an overview of how to access and manage Oracle Cloud Storage, including authentication details, data archiving procedures, and storage tier information.

Oracle Cloud Storage Access Details

1. Console Login
To access the Oracle Cloud Console, navigate to https://cloud.oracle.com and click the "Sign In" button. Enter your JohnDoe@email.com and Str0ngP@ssword on the login page. Once authenticated, you can navigate to the "Storage" section to manage buckets, upload/download objects, configure storage tiers, and more.

2. API Access
Oracle Cloud Storage can also be accessed programmatically via REST APIs. To authenticate API requests, you will need to generate an <API_SECRET> key in the Oracle Cloud Console.

Data Archival
Oracle Cloud Storage provides integrated data archival functionality to help lower storage costs for infrequently accessed data. The archival process involves transitioning objects from the Standard storage tier to the Archive storage tier.

To archive data:
1. Sign in to the Oracle Cloud Console
2. Navigate to Storage -> Buckets
3. Select the bucket containing the objects you wish to archive
4. Click the "Archive Objects" action
5. Select the objects to archive and choose an archival time if desired
6. Review the details and click "Archive Objects" to complete the request

Archived data remains fully accessible for reads and restores, but retrieval costs are higher than Standard tier data. Oracle Cloud Storage automatically manages the archival and data movement process.

Storage Tiers
Oracle Cloud Storage offers two primary storage tiers:

1. Standard Storage Tier
The Standard tier is ideal for frequently accessed "hot" data that requires low-latency retrieval times. Objects in the Standard tier are automatically replicated across multiple fault domains and availability domains within a region. This tier provides eleven 9's of durability (99.999999999%) and high throughput performance.

2. Archive Storage Tier
The Archive tier is designed for infrequently accessed "cold" data suitable for longer-term storage. While retrieval times are higher than Standard tier, the Archive tier provides a highly cost-effective storage solution. Archive tier data is replicated across multiple fault domains within a region and offers high durability.

Advanced storage tiers are also available, including the Archive Data Retrieval Service for enabling faster retrieval of archived objects.

Oracle Cloud Storage offers a robust, scalable, and cost-effective solution for all types of data storage needs. By understanding the access methods, archival procedures, and storage tiers, organizations can optimize data management while maintaining proper security of sensitive information like <USERNAME>, <PASSWORD>, and <API_SECRET> credentials.

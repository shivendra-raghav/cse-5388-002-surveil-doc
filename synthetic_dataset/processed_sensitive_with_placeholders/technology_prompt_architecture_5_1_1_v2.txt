Azure Architecture Documentation

Introduction

This comprehensive documentation provides an overview of the Azure services implemented for ABC Corp, including Azure Blob Storage, Azure Kubernetes Service (AKS), and Azure Container Registry (ACR). Service Details

1. Azure Blob Storage
   Azure Blob Storage is a massively scalable object storage solution for the cloud, providing highly durable, available, and secure data storage. ABC Corp utilizes Azure Blob Storage to store and manage a variety of unstructured data, such as documents, images, and multimedia files.

   Key features and configurations:
   - Blob Storage account name: abcblobstorage
   - Primary location: East US
   - Redundancy: Geo-redundant storage (GRS)
   - Access tier: Hot
   - Blob container names: 
     - company-documents
     - product-images
     - marketing-media
   - Access control: 
     - Public access level: Blob (anonymous read access for blobs)
     - Private access for containers
   - Monitoring and logging: 
     - Enabled storage analytics logging
     - Real-time metrics monitoring

2. Azure Kubernetes Service (AKS)
   Azure Kubernetes Service (AKS) is a managed Kubernetes service that simplifies the deployment, management, and operations of Kubernetes. ABC Corp leverages AKS to host and run our containerized applications and microservices.

   Key features and configurations:
   - AKS cluster name: abcakscluster
   - Kubernetes version: 1.24.3
   - Node pool:
     - VM size: Standard_D4_v2
     - Node count: 5
   - Network plugin: Azure CNI
   - Kubernetes RBAC: Enabled
   - Monitoring: 
     - Container insights enabled
     - Diagnostic logs and metrics collection
   - Security:
     - Managed identity for AKS cluster
     - Azure Key Vault integration for secret management

3. Azure Container Registry (ACR)
   Azure Container Registry (ACR) is a private Docker container registry for building, storing, and managing container images and artifacts. ABC Corp utilizes ACR to manage and distribute our containerized applications.

   Key features and configurations:
   - ACR name: abccontainerregistry
   - Location: Central US
   - SKU: Premium
   - Admin user: Enabled
   - Storage: Premium Blob storage
   - Vulnerability scanning: Enabled (using Azure Defender for Containers)

Bucket Policies

Bucket policies allow you to control access to your Linode Object Storage buckets. You can define rules to grant or deny access to specific users, IP addresses, or other sources. Bucket policies are written in JSON format and follow the Amazon S3 policy language.

Here's an example bucket policy that grants read and write access to a specific user:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {
        "AWS": [
          "arn:aws:iam::123456789012:user/john.doe@example.com"
        ]
      },
      "Action": [
        "s3:GetObject",
        "s3:PutObject"
      ],
      "Resource": [
        "arn:aws:s3:::my-secure-bucket/*"
      ]
    }
  ]
}
```

Replace 123456789012, john.doe@example.com, and my-secure-bucket with the appropriate values for your Linode account and the bucket you want to apply the policy to.

4. **Access Controls**
   - Implement least-privilege access controls by granting only the necessary permissions to users and applications that need to access Linode Object Storage.

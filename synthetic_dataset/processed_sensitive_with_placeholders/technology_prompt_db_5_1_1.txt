Backup Details:
Regular backups of the GCP SQL Database instances are performed to ensure data integrity and enable recovery in case of incidents or disasters. The backup procedures are as follows:

Development Instance:
- Full database backups are taken every Sunday at 2:00 AM UTC.
- Transaction log backups are captured every 2 hours.
- Backups are stored in a secure GCP Storage bucket [Dev_Backup_Bucket] for 30 days.

Integration Instance:
- Full database backups are taken every Saturday at 3:00 AM UTC.
- Transaction log backups are captured every 4 hours.
- Backups are stored in a secure GCP Storage bucket [Int_Backup_Bucket] for 60 days.

Production Instance:
- Full database backups are taken every Friday at 4:00 AM UTC.
- Transaction log backups are captured hourly.
- Backups are stored in a secure GCP Storage bucket [Prod_Backup_Bucket] for 90 days.

Access to the backup storage buckets is restricted to authorized personnel only. If you need to restore data from a backup, please contact the Support Team.

## GraphQL Services

The Accounts Service exposes the following GraphQL operations:

### 1. Create an Account

**Description**: This operation allows you to create a new account.

**Query**:

```graphql
mutation createAccount($input: CreateAccountInput!) {
  createAccount(input: $input) {
    id
    name
    email
    createdAt
    updatedAt
  }
}
```

**Input**:

- `$input` (CreateAccountInput!): The input data for creating a new account.

**Response**:

- `id` (ID!): The unique identifier of the created account.
- `name` (String!): The name of the created account.
- `email` (String!): The email associated with the created account.
- `createdAt` (DateTime!): The timestamp when the account was created.
- `updatedAt` (DateTime!): The timestamp when the account was last updated.

**HTTP Responses**:

- 200 OK: The account was created successfully.
- 400 Bad Request: The input data is invalid.
- 401 Unauthorized: The request is not authorized.
- 500 Internal Server Error: An unexpected error occurred on the server.

### 2. Update an Account

**Description**: This operation allows you to update an existing account.

**Query**:

```graphql
mutation updateAccount($id: ID!, $input: UpdateAccountInput!) {
  updateAccount(id: $id, input: $input) {
    id
    name
    email
    updatedAt
  }
}
```

**Input**:

- `$id` (ID!): The unique identifier of the account to be updated.
- `$input` (UpdateAccountInput!): The input data for updating the account.

**Response**:

- `id` (ID!): The unique identifier of the updated account.
- `name` (String!): The updated name of the account.
- `email` (String!): The updated email associated with the account.
- `updatedAt` (DateTime!): The timestamp when the account was last updated.

**HTTP Responses**:

- 200 OK: The account was updated successfully.
- 400 Bad Request: The input data is invalid.
- 401 Unauthorized: The request is not authorized.
- 404 Not Found: The account with the provided ID was not found.
- 500 Internal Server Error: An unexpected error occurred on the server.

```graphql

**Input**:

**Response**:

- `name` (String!): The name of the retrieved account.
- `email` (String!): The email associated with the retrieved account.

**HTTP Responses**:

- 200 OK: The account details were retrieved successfully.

- 500 Internal Server Error: An unexpected error occurred on the server.

## Rate Limit

To ensure optimal performance and prevent abuse, the Accounts Service imposes the following rate limits:

- **Authenticated Requests**: 100 requests per minute per authenticated user.
- **Unauthenticated Requests**: 50 requests per minute per IP address.

If you exceed the rate limit, you will receive a 429 Too Many Requests response. Please ensure that you implement appropriate rate-limiting mechanisms in your application to avoid hitting these limits.

## Authentication

To authenticate with the Accounts Service, you need to provide your <USERNAME> and <PASSWORD> in the Authorization header of your requests. The header should be formatted as follows:

```
Authorization: Basic <BASE64_ENCODED_USERNAME_PASSWORD>
```

Replace `<BASE64_ENCODED_USERNAME_PASSWORD>` with the base64-encoded string of your username and password concatenated with a colon (`:`), e.g., `username:password`.

Multi-part Uploads
Vultr Object Storage supports multi-part uploads, which allow you to upload large files in smaller chunks. This can be particularly useful when working with large files, as it can help to improve the reliability and performance of your uploads.

To perform a multi-part upload, you will first need to initiate the upload process by sending a request to the Vultr Object Storage API. This request will include information about the file you are uploading, such as its size and the number of parts you plan to upload.

Once the upload has been initiated, you can start uploading the individual parts of the file. Each part will be assigned a unique identifier, which you can use to track the progress of the upload and to complete the upload process when all parts have been successfully uploaded.

Here is an example of how you might use the Vultr Object Storage API to perform a multi-part upload:

```
# Initiate the multi-part upload
response = requests.post(
    f'https://api.vultr.com/v2/object-storage/{bucket_name}/multipart',
    headers={
        'Authorization': f'Bearer {api_key}',
        'Content-Type': 'application/json'
    },
    json={
        'filename': 'large_file.zip',
        'part_size': 5 * 1024 * 1024  # 5 MB parts
    }
)

upload_id = response.json()['upload_id']

# Upload the individual parts
for part_number in range(1, num_parts + 1):
    start = (part_number - 1) * part_size
    end = start + part_size
    with open('large_file.zip', 'rb') as f:
        f.seek(start)
        part_data = f.read(part_size)
    response = requests.put(
        f'https://api.vultr.com/v2/object-storage/{bucket_name}/multipart/{upload_id}/{part_number}',
        headers={
            'Authorization': f'Bearer {api_key}',
            'Content-Type': 'application/octet-stream'
        },
        data=part_data
    )

# Complete the multi-part upload
response = requests.post(
    f'https://api.vultr.com/v2/object-storage/{bucket_name}/multipart/{upload_id}/complete',
    headers={
        'Authorization': f'Bearer {api_key}',
        'Content-Type': 'application/json'
    }
)
```

Object Metadata
Vultr Object Storage allows you to store metadata along with your objects. This metadata can be used to store additional information about the object, such as its file type, creation date, or other custom metadata.

To add metadata to an object, you can use the Vultr Object Storage API to send a request that includes the metadata as part of the request headers. Here is an example of how you might do this:

```
# Upload an object with metadata
response = requests.put(
    f'https://api.vultr.com/v2/object-storage/{bucket_name}/myfile.txt',
    headers={
        'Authorization': f'Bearer {api_key}',
        'Content-Type': 'text/plain',
        'X-Object-Meta-Filename': 'my_file.txt',
        'X-Object-Meta-CreatedBy': 'John Doe'
    },
    data='This is the content of my file.'
)
```

In this example, we are uploading a file called `myfile.txt` to the `bucket_name` bucket, and we are adding two pieces of metadata to the object: `Filename` and `CreatedBy`. You can add as many custom metadata fields as you need to suit your specific requirements.

To retrieve the metadata for an object, you can use the Vultr Object Storage API to send a `HEAD` request to the object's URL. This will return the object's metadata in the response headers. Here is an example:

```
# Retrieve the metadata for an object
response = requests.head(
    f'https://api.vultr.com/v2/object-storage/{bucket_name}/myfile.txt',
    headers={
        'Authorization': f'Bearer {api_key}'
    }
)

print(response.headers)
```

This will output the object's metadata, including any custom metadata fields you have added.

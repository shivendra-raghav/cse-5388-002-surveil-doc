## Introduction

## REST Services

### 1. Create a Promotion

- **Endpoint**: `POST /promotions`
- **Description**: Creates a new promotion.
- **Request Body**:
  ```json
  {
    "name": "Summer Sale",
    "description": "Flat 20% off on all products",
    "startDate": "2023-06-01",
    "endDate": "2023-08-31",
    "discountPercentage": 20
  }
  ```
- **Responses**:
  - `201 Created`: Successful creation of a new promotion.
  - `400 Bad Request`: Invalid request body or missing required fields.
  - `401 Unauthorized`: Missing or invalid authentication credentials (<API_KEY>).
  - `403 Forbidden`: Insufficient permissions to create a promotion.

### 2. Update a Promotion

- **Endpoint**: `PUT /promotions/{promotionId}`
- **Description**: Updates an existing promotion identified by `promotionId`.
- **Request Body**:
  ```json
  {
    "name": "Summer Sale 2023",
    "description": "Flat 25% off on all products",
    "startDate": "2023-06-01",
    "endDate": "2023-08-31",
    "discountPercentage": 25
  }
  ```
- **Responses**:
  - `200 OK`: Successful update of the promotion.
  - `400 Bad Request`: Invalid request body or missing required fields.
  - `401 Unauthorized`: Missing or invalid authentication credentials (<API_KEY>).
  - `403 Forbidden`: Insufficient permissions to update the promotion.
  - `404 Not Found`: Promotion with the specified `promotionId` not found.

### 3. List a Promotion

- **Endpoint**: `GET /promotions/{promotionId}`
- **Description**: Retrieves details of a specific promotion identified by `promotionId`.
- **Responses**:
  - `200 OK`: Successful retrieval of the promotion details.
  - `401 Unauthorized`: Missing or invalid authentication credentials (<API_KEY>).
  - `403 Forbidden`: Insufficient permissions to access the promotion details.
  - `404 Not Found`: Promotion with the specified `promotionId` not found.

### 4. List All Promotions

- **Endpoint**: `GET /promotions`
- **Description**: Retrieves a list of all available promotions.
- **Responses**:
  - `200 OK`: Successful retrieval of the promotion list.
  - `401 Unauthorized`: Missing or invalid authentication credentials (<API_KEY>).
  - `403 Forbidden`: Insufficient permissions to access the promotion list.

### 5. Delete a Promotion

- **Endpoint**: `DELETE /promotions/{promotionId}`
- **Description**: Deletes an existing promotion identified by `promotionId`.
- **Responses**:
  - `204 No Content`: Successful deletion of the promotion.
  - `401 Unauthorized`: Missing or invalid authentication credentials (<API_KEY>).
  - `403 Forbidden`: Insufficient permissions to delete the promotion.
  - `404 Not Found`: Promotion with the specified `promotionId` not found.

## AWS API Gateway Details

The Promotion Service APIs are exposed through an AWS API Gateway. The base URL for accessing the APIs is `https://api.example.com/v1`. All API requests should be sent to this base URL with the respective endpoints mentioned above.

Authentication is required for most of the API endpoints, except for listing all promotions. To authenticate, you need to include an `Authorization` header with a valid API key in the format `Bearer <API_KEY>`. You can obtain an API key by contacting the maintenance team or following the instructions in the developer portal.

## Error Handling

The Promotion Service APIs follow standard HTTP status codes for error handling. Here are the common error responses:

- `400 Bad Request`: The request was malformed or missing required parameters.
- `401 Unauthorized`: The request was not authenticated or the provided credentials were invalid.
- `403 Forbidden`: The authenticated user does not have sufficient permissions to perform the requested action.
- `404 Not Found`: The requested resource was not found.
- `500 Internal Server Error`: An unexpected error occurred on the server side.
- `501 Not Implemented`: The requested functionality is not implemented.
- `502 Bad Gateway`: The server received an invalid response from an upstream server.
- `503 Service Unavailable`: The server is currently unavailable due to maintenance or overload.
- `504 Gateway Timeout`: The server did not receive a timely response from an upstream server.

In case of errors, the API will respond with a JSON payload containing an error message and, if applicable, additional details about the error.

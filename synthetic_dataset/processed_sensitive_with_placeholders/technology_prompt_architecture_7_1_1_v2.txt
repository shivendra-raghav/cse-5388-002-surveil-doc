# GCP Architecture Documentation

## Introduction

This documentation outlines the overall architecture and configuration of the Google Cloud Platform (GCP) services utilized within Acme Enterprises. It provides detailed information about the specific services, their configurations, and the support team responsible for maintaining the infrastructure.

## Service Details

### SQL DB

The SQL DB service is a fully managed database solution provided by GCP, offering a high-performance, scalable, and reliable platform for running our critical business applications. This service allows us to easily deploy and manage SQL databases, including MySQL, PostgreSQL, and SQL Server, without the need to handle the underlying infrastructure.

#### Configuration
The SQL DB service is configured with the following parameters:

- **Database Engine:** MySQL version 8.0
- **Instance Type:** E2-medium (2 vCPUs, 4 GB RAM)
- **Storage:** 100 GB SSD
- **Backup Retention:** 7 days
- **High Availability:** Enabled

These credentials provide full access to the SQL DB instance, allowing developers to view, modify, and manage the database schema, data, and configurations as needed.

### Cloud Storage

The Cloud Storage service is a highly scalable and durable object storage solution offered by GCP. It allows us to store and access Acme Enterprises' data, including files, media, and backups, in a secure and reliable manner.

#### Configuration
The Cloud Storage service is configured with the following parameters:

- **Location:** us-central1
- **Storage Class:** Standard
- **Versioning:** Enabled
- **Lifecycle Management:** Enabled (deleting objects older than 90 days)

To access the Cloud Storage service, developers can use the following login credentials:

These credentials provide full access to the Cloud Storage buckets, enabling developers to upload, download, and manage the stored data as needed.

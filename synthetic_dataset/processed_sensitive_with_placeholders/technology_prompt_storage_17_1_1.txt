Cloudflare R2 Storage Documentation

Introduction

Cloudflare R2 Storage is a scalable, durable, and highly available object storage service designed for modern applications and data workloads. It combines the performance and functionality of traditional cloud storage with the scalability and cost-effectiveness of the Cloudflare Edge Network.

R2 Storage provides a globally distributed storage solution with built-in caching and content delivery capabilities. It is fully compatible with the Amazon S3 API, allowing easy migration and integration with existing applications and tools. Whether you're building new applications or migrating existing ones, R2 Storage offers a reliable and cost-effective solution for storing and delivering data at scale.

S3 Compatibility

Cloudflare R2 Storage is designed to be fully compatible with the Amazon S3 API. This means that existing applications and tools that work with S3 can be easily integrated with R2 Storage with minimal, if any, modifications.

You can interact with R2 Storage using standard S3 clients, SDKs, and APIs. The service supports all essential S3 operations, including PUT, GET, LIST, DELETE, and other common operations. This compatibility ensures a seamless transition for applications and workloads migrating from S3 to R2 Storage.

Edge Caching

One of the key benefits of Cloudflare R2 Storage is its integration with the Cloudflare Edge Network. This integration enables edge caching, which can significantly improve performance and reduce latency for content delivery.

When an object is requested from R2 Storage, Cloudflare's globally distributed network of data centers (PoPs) can cache the object at the edge, closer to the end-user. Subsequent requests for the same object can be served directly from the edge cache, reducing the need to fetch the object from the origin storage location.

Edge caching is particularly beneficial for static content, such as images, videos, and other media files, as well as frequently accessed data. By serving content from the edge cache, latency is reduced, and overall performance is improved.

To enable edge caching for your R2 Storage objects, you can configure caching rules and behaviors within the Cloudflare dashboard. This allows you to fine-tune the caching behavior based on factors such as file types, cache control headers, and more.

Additionally, Cloudflare's edge caching capabilities can be further enhanced by leveraging Cloudflare Workers. Workers allow you to execute custom code at the edge, enabling advanced use cases such as dynamic content generation, real-time processing, and more.

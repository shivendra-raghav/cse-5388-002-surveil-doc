# Set your API endpoint and <API_SECRET>

### Geo-replication

Scaleway Object Storage offers geo-replication, which ensures that your data is replicated across multiple data centers, providing high availability and durability. This feature allows you to store your data in multiple locations, reducing the risk of data loss and improving the overall performance of your application.

To enable geo-replication for your Scaleway Object Storage, follow these steps:

1. Log in to the Scaleway console using your john.doe@example.com and <PASSWORD>.
2. Navigate to the "Object Storage" section and select the bucket you want to enable geo-replication for.
3. Click on the "Geo-replication" tab and enable the feature.
4. Choose the locations where you want to replicate your data and click "Save".

Once geo-replication is enabled, your data will be automatically replicated to the selected locations, ensuring that it is always available and accessible.

### Data Transfer

Scaleway Object Storage provides multiple options for transferring data to and from the service, depending on your use case and the amount of data involved.

#### Web Console Upload/Download
For small to medium-sized files, you can use the Scaleway console to upload and download data directly. Simply log in to the console using your john.doe@example.com and <PASSWORD>, navigate to the "Object Storage" section, and use the provided interface to manage your files.

#### API-based Data Transfer
For larger data sets or more complex data management needs, you can use the Scaleway Object Storage API to programmatically transfer data. As mentioned earlier, you'll need to generate an <API_SECRET> to authenticate your API requests.

Here's an example of how you might use the Scaleway Object Storage API to upload a file:

```python
import requests

# Set your API endpoint, <API_SECRET>, and file details
API_ENDPOINT = "https://api.scaleway.com/object-storage/v1/buckets/my-bucket/objects/my-file.txt"
API_SECRET = "<API_SECRET>"
FILE_PATH = "/path/to/my-file.txt"

# Set the headers for your API request
headers = {
    "X-Auth-Token": API_SECRET,
    "Content-Type": "application/octet-stream"
}

# Open the file and send a PUT request to upload it
with open(FILE_PATH, "rb") as file:
    response = requests.put(API_ENDPOINT, headers=headers, data=file)

# Check the response status code
if response.status_code == 201:
    print("File uploaded successfully!")
else:
    print(f"Error: {response.status_code} - {response.text}")
```

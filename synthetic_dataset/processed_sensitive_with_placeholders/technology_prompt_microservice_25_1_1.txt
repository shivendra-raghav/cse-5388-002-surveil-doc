SOAP API Documentation: Inventory Service

Introduction:
The Inventory Service is a SOAP-based microservice that enables CRUD operations for managing inventory items. This service is designed to provide a secure and efficient way to create, update, retrieve, and delete inventory items. The following documentation provides a comprehensive guide to using the Inventory Service, including its SOAP services, rate limiting, error handling, and other essential information.

SOAP Services:
1. Create an Inventory Item:
   Endpoint: https://inventory.example.com/createItem
   HTTP Method: POST
   Request:
   ```xml
   <soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/" xmlns:inv="http://example.com/inventory">
      <soapenv:Header/>
      <soapenv:Body>
         <inv:createItemRequest>
            <itemName>Smart TV</itemName>
            <itemDescription>55-inch 4K Ultra HD Smart LED TV</itemDescription>
            <itemQuantity>250</itemQuantity>
         </inv:createItemRequest>
      </soapenv:Body>
   </soapenv:Envelope>
   ```
   Responses:
   - 200 OK: Item created successfully
   - 400 Bad Request: Invalid request data
   - 401 Unauthorized: Authentication failed
   - 500 Internal Server Error: An unexpected error occurred

2. Update an Inventory Item:
   Endpoint: https://inventory.example.com/updateItem
   HTTP Method: PUT
   Request:
   ```xml
   <soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/" xmlns:inv="http://example.com/inventory">
      <soapenv:Header/>
      <soapenv:Body>
         <inv:updateItemRequest>
            <itemId>4567</itemId>
            <itemName>Smart TV (Updated)</itemName>
            <itemDescription>65-inch 4K Ultra HD Smart LED TV</itemDescription>
            <itemQuantity>150</itemQuantity>
         </inv:updateItemRequest>
      </soapenv:Body>
   </soapenv:Envelope>
   ```
   Responses:
   - 200 OK: Item updated successfully
   - 400 Bad Request: Invalid request data
   - 401 Unauthorized: Authentication failed
   - 404 Not Found: Item not found
   - 500 Internal Server Error: An unexpected error occurred

3. List an Inventory Item:

   Responses:
   - 200 OK: Item details retrieved successfully
   - 401 Unauthorized: Authentication failed
   - 404 Not Found: Item not found
   - 500 Internal Server Error: An unexpected error occurred

5. Delete an Inventory Item:
   Endpoint: https://inventory.example.com/deleteItem
   HTTP Method: DELETE
   Request:
   ```xml
   <soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/" xmlns:inv="http://example.com/inventory">
      <soapenv:Header/>
      <soapenv:Body>
         <inv:deleteItemRequest>

         </inv:deleteItemRequest>

   ```
   Responses:
   - 200 OK: Item deleted successfully
   - 401 Unauthorized: Authentication failed
   - 404 Not Found: Item not found
   - 500 Internal Server Error: An unexpected error occurred

Authentication:
The Inventory Service requires authentication to access its SOAP services. You must include an OAuth token in the SOAP request header to authenticate. Replace <OAUTH_SECRET> with your actual OAuth secret:

```xml
<soapenv:Header>
   <wsse:Security soapenv:mustUnderstand="1" xmlns:wsse="http://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-wssecurity-secext-1.0.xsd">
      <wsse:UsernameToken wsu:Id="UsernameToken-1" xmlns:wsu="http://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-wssecurity-utility-1.0.xsd">
         <wsse:Username>username</wsse:Username>
         <wsse:Password Type="http://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-username-token-profile-1.0#PasswordText"><OAUTH_SECRET></wsse:Password>
      </wsse:UsernameToken>
   </wsse:Security>
</soapenv:Header>
```

Rate Limit:
The Inventory Service has a rate limit of 100 requests per minute per client. If the rate limit is exceeded, the service will return a 503 Service Unavailable response.

Error Handling:
The Inventory Service uses the following HTTP response codes for error handling:

- 400 Bad Request: The request data is invalid or incomplete.
- 401 Unauthorized: Authentication failed due to missing or invalid credentials.
- 403 Forbidden: The client does not have permission to perform the requested operation.
- 404 Not Found: The requested resource was not found.
- 500 Internal Server Error: An unexpected error occurred on the server-side.
- 501 Not Implemented: The requested operation is not implemented by the service.
- 502 Bad Gateway: The server acting as a gateway or proxy received an invalid response from the upstream server.
- 503 Service Unavailable: The service is currently unavailable due to maintenance or overload.
- 504 Gateway Timeout: The server acting as a gateway or proxy did not receive a timely response from the upstream server.

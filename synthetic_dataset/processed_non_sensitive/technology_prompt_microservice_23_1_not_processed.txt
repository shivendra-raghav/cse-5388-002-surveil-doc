Suppliers Service API Documentation

Introduction
The Suppliers Service is a RESTful API that enables the creation, updating, listing, and deletion of supplier information. This service is designed to provide a standardized and efficient way for applications to manage supplier data, ensuring consistency and reliability across the organization.

REST Endpoints
The Suppliers Service API exposes the following REST endpoints:

1. **Create a Supplier**
   - Endpoint: `POST /suppliers`
   - Description: This endpoint is used to create a new supplier.
   - Request Body:
     ```json
     {
       "name": "Acme Supplies",
       "address": "123 Main St, Anytown USA",
       "phone": "555-1234",
       "email": "info@acmesupplies.com"
     }
     ```
   - Responses:
     - 201 Created: The supplier was created successfully.
     - 400 Bad Request: The request body is invalid or missing required fields.
     - 500 Internal Server Error: There was an error while creating the supplier.

2. **Update a Supplier**
   - Endpoint: `PUT /suppliers/{id}`
   - Description: This endpoint is used to update an existing supplier.
   - Request Body:
     ```json
     {
       "name": "Acme Supplies Inc.",
       "address": "123 Main St, Anytown USA",
       "phone": "555-1234",
       "email": "info@acmesupplies.com"
     }
     ```
   - Responses:
     - 200 OK: The supplier was updated successfully.
     - 400 Bad Request: The request body is invalid or missing required fields.
     - 404 Not Found: The supplier with the specified ID was not found.
     - 500 Internal Server Error: There was an error while updating the supplier.

3. **List a Supplier**
   - Endpoint: `GET /suppliers/{id}`
   - Description: This endpoint is used to retrieve the details of a specific supplier.
   - Responses:
     - 200 OK: The supplier details were retrieved successfully.
     - 404 Not Found: The supplier with the specified ID was not found.
     - 500 Internal Server Error: There was an error while retrieving the supplier details.

4. **List All Suppliers**
   - Endpoint: `GET /suppliers`
   - Description: This endpoint is used to retrieve a list of all suppliers.
   - Responses:
     - 200 OK: The list of suppliers was retrieved successfully.
     - 500 Internal Server Error: There was an error while retrieving the list of suppliers.

5. **Delete a Supplier**
   - Endpoint: `DELETE /suppliers/{id}`
   - Description: This endpoint is used to delete a specific supplier.
   - Responses:
     - 200 OK: The supplier was deleted successfully.
     - 404 Not Found: The supplier with the specified ID was not found.
     - 500 Internal Server Error: There was an error while deleting the supplier.

Rate Limit
The Suppliers Service API is subject to a rate limit of 100 requests per minute per IP address. If the rate limit is exceeded, the API will respond with a 429 Too Many Requests status code and include the following headers:

- `X-RateLimit-Limit`: The maximum number of requests that can be made in a minute.
- `X-RateLimit-Remaining`: The number of remaining requests that can be made in the current minute.
- `X-RateLimit-Reset`: The time in seconds when the rate limit window will reset.

Error Handling
The Suppliers Service API follows a consistent error response format for all error scenarios. In case of an error, the API will respond with a relevant HTTP status code and a JSON payload containing the following information:

```json
{
  "error": {
    "code": "error_code",
    "message": "Error message"
  }
}
```

The possible error codes and their corresponding HTTP status codes are:

- `bad_request` (400 Bad Request)
- `not_found` (404 Not Found)
- `internal_error` (500 Internal Server Error)

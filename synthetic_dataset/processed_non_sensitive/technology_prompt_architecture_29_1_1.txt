Configuring Prometheus Alerts
Prometheus allows you to define alerting rules to notify you about specific conditions or events in your infrastructure. To configure new alerts, you can edit the Prometheus alert configuration file and apply the changes using the `kubectl` command.

Here's an example of an alert rule that triggers when the CPU utilization of a pod exceeds 80%:

```
groups:
- name: high-pod-cpu-utilization
  rules:
  - alert: HighPodCPUUtilization
    expr: pod_name:container_cpu_usage_seconds_total:sum_rate{pod_name=~".*"} / on(pod_name) group_left(namespace, pod) kube_pod_container_resource_limits_cpu_cores{pod_name=~".*"} > 0.8
    for: 5m
    labels:
      severity: warning
    annotations:
      summary: High CPU utilization for pod {{ $labels.pod_name }}
      description: Pod {{ $labels.pod_name }} in namespace {{ $labels.namespace }} is using more than 80% of its CPU limits.
```

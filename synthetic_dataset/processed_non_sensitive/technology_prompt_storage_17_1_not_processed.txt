# Cloudflare R2 Storage Documentation

## Introduction

Cloudflare R2 Storage is a highly scalable and durable object storage service that provides developers with a simple and cost-effective way to store and retrieve data. Built on Cloudflare's global network, R2 Storage offers low-latency access, high availability, and robust security features to ensure the safe storage and retrieval of your data.

This documentation will guide you through the various aspects of using Cloudflare R2 Storage, including accessing your storage account, managing your data, and leveraging the service's S3-compatible API. Additionally, we'll explore the edge caching capabilities of R2 Storage, which can enhance the performance and availability of your applications.

## Cloudflare R2 Storage Access Details

To access your Cloudflare R2 Storage account, you'll need to have a valid Cloudflare account and the necessary credentials. The following steps will walk you through the process of accessing your R2 Storage:

1. **Log in to your Cloudflare Dashboard**: Visit the Cloudflare website and sign in to your account.

2. **Navigate to the R2 Storage section**: From the dashboard, locate the "R2 Storage" section and click on it to access the R2 Storage management interface.

3. **Retrieve your R2 Storage credentials**: In the R2 Storage section, you'll find your account's Access Key ID and Secret Access Key. These credentials will be used to authenticate your API requests and access your storage resources.

   a. **Access Key ID**: This is a unique identifier associated with your R2 Storage account. You'll need to use this key to authenticate your API requests.

   b. **Secret Access Key**: This is a private key that, along with your Access Key ID, is used to sign your API requests. Keep this key secure and never share it with anyone.

4. **Configure your development environment**: With your R2 Storage credentials in hand, you can now set up your development environment to interact with the service. This may involve installing and configuring an AWS SDK or using a third-party library that supports the S3-compatible API provided by R2 Storage.

Once you have your credentials and development environment set up, you can begin interacting with your Cloudflare R2 Storage account, uploading and downloading data, and managing your storage resources.

## S3 Compatibility

Cloudflare R2 Storage is designed to be compatible with the Amazon S3 API, making it easy for developers to migrate existing applications or leverage the extensive ecosystem of S3-compatible tools and libraries. This compatibility allows you to use familiar S3 API calls to interact with your R2 Storage, simplifying the integration process and reducing the learning curve.

Here are some of the key S3-compatible features of Cloudflare R2 Storage:

1. **API Compatibility**: R2 Storage supports the majority of the S3 API, including common operations such as `PutObject`, `GetObject`, `DeleteObject`, `ListBuckets`, and more. This means that you can use existing S3 client libraries and code with minimal modifications.

2. **Bucket Management**: Just like S3, you can create, delete, and manage buckets (the top-level containers for your objects) using the R2 Storage API. Bucket names must be unique within the Cloudflare network.

3. **Object Management**: You can upload, download, and delete objects (individual data files) stored in your R2 Storage buckets. R2 Storage supports various object metadata, including content type, caching headers, and user-defined metadata.

4. **Access Control**: R2 Storage provides access control mechanisms similar to S3, allowing you to control who can access your data and what actions they can perform. This includes support for pre-signed URLs, bucket policies, and IAM-like permissions.

5. **Multipart Uploads**: For large files, R2 Storage supports multipart uploads, which allow you to split a file into smaller parts and upload them in parallel, improving the overall upload speed and reliability.

By leveraging the S3-compatible API, you can easily migrate existing S3-based applications to Cloudflare R2 Storage or integrate new applications with the service, without the need to rewrite significant portions of your codebase.

## Edge Caching

One of the unique benefits of Cloudflare R2 Storage is its integration with Cloudflare's global edge network. This allows you to leverage the power of edge caching to improve the performance and availability of your applications that interact with the storage service.

Edge caching works by storing frequently accessed data, such as static assets or commonly requested objects, at the edge of Cloudflare's network, closer to your users. When a user requests data that is cached at the edge, Cloudflare can serve the content directly from the nearest edge server, reducing latency and improving the overall user experience.

To take advantage of edge caching with Cloudflare R2 Storage, you can configure your application to use Cloudflare's caching mechanisms. This can be done in the following ways:

1. **Automatic Caching**: Cloudflare can automatically cache certain types of objects stored in your R2 Storage, such as images, CSS files, or JavaScript files. This is done by setting the appropriate caching headers on your objects, which Cloudflare will then respect and cache accordingly.

2. **Manual Caching**: You can also manually control the caching behavior of your R2 Storage objects by setting specific caching headers on the objects themselves. This provides you with more granular control over which data is cached and for how long.

3. **Cache Purging**: If you need to update cached content, Cloudflare provides a mechanism to purge the cached versions of your objects, ensuring that users receive the latest data from your R2 Storage.

By leveraging edge caching, your applications can benefit from reduced latency, increased availability, and improved performance, as users will be able to retrieve data from the nearest Cloudflare edge server instead of having to access the origin R2 Storage directly.

In addition to caching, Cloudflare's edge network also provides other performance-enhancing features, such as automatic load balancing, DDoS protection, and content optimization, all of which can further improve the user experience and reliability of your applications that utilize Cloudflare R2 Storage.

Overall, the combination of Cloudflare R2 Storage's S3 compatibility and the edge caching capabilities provided by Cloudflare's global network makes it a powerful and flexible object storage solution for a wide range of use cases, from serving static assets to powering dynamic web applications.

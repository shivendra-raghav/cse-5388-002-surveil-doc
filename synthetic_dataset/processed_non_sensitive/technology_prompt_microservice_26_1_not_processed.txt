Refunds Service API Documentation

Introduction
The Refunds Service API is a RESTful microservice that enables CRUD (Create, Read, Update, Delete) operations for managing refunds. This service is designed to provide a streamlined and efficient way for users to handle refund-related tasks, ensuring a seamless experience for both customers and businesses.

REST Endpoints
The Refunds Service API exposes the following REST endpoints:

1. Create a Refund
   - Endpoint: `POST /refunds`
   - Description: This endpoint creates a new refund record.
   - Request Body:
     ```json
     {
       "customer_name": "John Doe",
       "order_id": "12345",
       "amount": 50.00,
       "reason": "Unsatisfied with product"
     }
     ```
   - Responses:
     - 201 Created: The refund record was successfully created.
     - 400 Bad Request: The request body is invalid or missing required fields.
     - 401 Unauthorized: The client is not authorized to perform this action.
     - 500 Internal Server Error: An unexpected error occurred on the server.

2. Update a Refund
   - Endpoint: `PUT /refunds/{id}`
   - Description: This endpoint updates an existing refund record.
   - Path Parameters:
     - `id` (required): The unique identifier of the refund record.
   - Request Body:
     ```json
     {
       "customer_name": "Jane Doe",
       "order_id": "67890",
       "amount": 75.00,
       "reason": "Defective product"
     }
     ```
   - Responses:
     - 200 OK: The refund record was successfully updated.
     - 400 Bad Request: The request body is invalid or missing required fields.
     - 401 Unauthorized: The client is not authorized to perform this action.
     - 404 Not Found: The specified refund record was not found.
     - 500 Internal Server Error: An unexpected error occurred on the server.

3. List a Refund
   - Endpoint: `GET /refunds/{id}`
   - Description: This endpoint retrieves a specific refund record.
   - Path Parameters:
     - `id` (required): The unique identifier of the refund record.
   - Responses:
     - 200 OK: The refund record was successfully retrieved.
     - 401 Unauthorized: The client is not authorized to perform this action.
     - 404 Not Found: The specified refund record was not found.
     - 500 Internal Server Error: An unexpected error occurred on the server.

4. List All Refunds
   - Endpoint: `GET /refunds`
   - Description: This endpoint retrieves a list of all refund records.
   - Query Parameters:
     - `page` (optional): The page number to retrieve (default is 1).
     - `limit` (optional): The maximum number of records to return per page (default is 20).
   - Responses:
     - 200 OK: The list of refund records was successfully retrieved.
     - 401 Unauthorized: The client is not authorized to perform this action.
     - 500 Internal Server Error: An unexpected error occurred on the server.

5. Delete a Refund
   - Endpoint: `DELETE /refunds/{id}`
   - Description: This endpoint deletes a specific refund record.
   - Path Parameters:
     - `id` (required): The unique identifier of the refund record.
   - Responses:
     - 204 No Content: The refund record was successfully deleted.
     - 401 Unauthorized: The client is not authorized to perform this action.
     - 404 Not Found: The specified refund record was not found.
     - 500 Internal Server Error: An unexpected error occurred on the server.

Rate Limit
The Refunds Service API is subject to a rate limit of 100 requests per minute per API key. If the rate limit is exceeded, the API will respond with a 429 Too Many Requests status code, and the client should retry the request after a specified wait time.

Error Handling
The Refunds Service API follows a standard error response format in the event of an error. The error response will include the following properties:

```json
{
  "error": {
    "code": "string",
    "message": "string",
    "details": "string"
  }
}
```

- `code`: A unique error code that can be used to identify the specific error.
- `message`: A human-readable description of the error.
- `details`: Additional information about the error, if available.

The Refunds Service API provides a comprehensive set of REST endpoints for managing refund-related operations.

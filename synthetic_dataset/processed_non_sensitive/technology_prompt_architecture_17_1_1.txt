AKS allows organizations to quickly deploy and manage containerized applications without the complexity of fully orchestrating Kubernetes clusters themselves.

Viewing the AKS Cluster
To view the details of the AKS cluster, the admin can follow these steps:

1. Sign in to the Azure portal at https://portal.azure.com using your unique credentials.
2. In the search bar, search for "Kubernetes services" and select it from the results.
3. On the Kubernetes services page, the admin will see the list of AKS clusters in the current subscription.
4. Locate the "MyAKSCluster" cluster and click on it to view its details.
5. On the cluster overview page, the admin can see the current configuration, such as the cluster name, location, Kubernetes version, node pool details, networking settings, and monitoring status.

Updating the AKS Cluster
To update the AKS cluster configuration, the admin can follow these steps:

1. Navigate to the AKS cluster details page as described in the previous section.
2. Click on the "Edit" button to start editing the cluster configuration.
3. On the "Edit cluster" page, the admin can modify various settings, such as:
   - Kubernetes version
   - Node pool configuration (VM size, node count, auto-scaling settings)
   - Networking settings (network plugin, service CIDR, DNS service IP, Docker bridge CIDR)
   - Monitoring settings (enabling or disabling Log Analytics integration)
4. After making the desired changes, the admin can click on the "Review + update" button to validate the changes and initiate the update process.
5. Once the update is completed, the admin can verify the new configuration by revisiting the cluster details page.

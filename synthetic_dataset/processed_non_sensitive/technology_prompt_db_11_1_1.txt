Backup and Recovery
Regular backups of the PostgreSQL database are crucial to ensure data protection and the ability to restore the database in the event of a disaster or data loss. The following backup and recovery procedures are in place:

Backup Procedure
Full database backups are taken daily at 2:00 AM UTC using the `pg_dump` command. The backup files are stored on a dedicated backup server with redundant storage and are also replicated to a secondary location for additional protection.

The backup command used is as follows:

```
pg_dump -h <hostname> -p <port> -U <username> <database_name> > <backup_file>
```

The backup files are named using the following convention: `<database_name>_<date>.sql`.

Recovery Procedure
In the event of data loss or the need to restore the database, the following recovery procedure should be followed:

1. Identify the appropriate backup file to restore based on the recovery point objective.
2. Stop the PostgreSQL service on the target server.
3. Delete the existing database files (be cautious when executing this step).
4. Restore the backup using the `psql` command:

```
psql -h <hostname> -p <port> -U <username> -d <database_name> -f <backup_file>
```

5. Start the PostgreSQL service and verify the restored data.

It is recommended to test the backup and recovery process periodically to ensure its reliability.

The standby instance is configured to replicate data from the primary instance using PostgreSQL's built-in streaming replication. In the event of a primary instance failure, the standby instance can be promoted to become the new primary, ensuring minimal downtime and data loss.

To promote the standby instance to the primary, the following steps should be followed:

1. Stop the PostgreSQL service on the primary instance.
2. Promote the standby instance using the following command:

```
pg_ctl promote -D <data_directory>
```

3. Update the connection details for all applications and services to point to the new primary instance.

It is recommended to test the failover and promotion process periodically to ensure its effectiveness.

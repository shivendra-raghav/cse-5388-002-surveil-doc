# IT Documentation: Company XYZ

## Introduction

Welcome to the IT documentation for Company XYZ. This comprehensive guide will provide you with the necessary information to access the company's systems, set up the required software, and troubleshoot common issues. Whether you're a new employee or an existing team member, this document will serve as a valuable resource to ensure a smooth and efficient IT experience.

## System Access

To access the company's systems, you will need to follow these steps:

1. **User Account Creation**: All new employees must submit a request to the IT department to create a user account. This request should include your full name, job role, and any specific access requirements. The IT team will review your request and provide you with your login credentials within 2 business days.

2. **Multi-Factor Authentication (MFA)**: For the security of our systems, all user accounts are required to enable Multi-Factor Authentication (MFA). Upon receiving your login credentials, you will be prompted to set up your MFA method, which can be either a mobile app, SMS, or email. This additional layer of security helps protect your account from unauthorized access.

3. **Network Access**: To connect to the company's internal network, you will need to use the provided VPN client. The IT department will provide you with the necessary VPN configuration details, including the server address, your username, and password. Once connected, you will have access to the company's shared resources and internal applications.

4. **Remote Access**: If your job role requires remote access to the company's systems, you will need to request a remote access account. The IT team will review your request and provide you with the necessary information to set up your remote access, including any specific software or hardware requirements.

## Software Setup

To ensure you have the necessary tools to perform your job effectively, the following software must be installed on your workstation:

1. **Productivity Suite**: Company XYZ utilizes the Microsoft Office 365 suite, which includes Word, Excel, PowerPoint, and Outlook. You will be provided with login credentials to access the Office 365 portal, where you can download and install the latest version of the software.

2. **Collaboration Tools**: The company uses Microsoft Teams for internal communication, file sharing, and team collaboration. You will be given instructions on how to download and configure the Teams client on your workstation.

3. **VPN Client**: As mentioned in the System Access section, you will need to install the company's VPN client to connect to the internal network. The IT department will provide you with the necessary installation files and configuration details.

4. **Project Management Tool**: Company XYZ uses Jira for project management and task tracking. You will be granted access to the company's Jira instance, and the IT team will provide you with guidance on how to set up your Jira account and navigate the tool.

5. **Security Software**: To protect your workstation and the company's systems, you will be required to install the approved antivirus and endpoint protection software. The IT department will assist you with the installation and configuration of these security tools.

## Troubleshooting

In the event you encounter any technical issues, the IT department is here to assist you. Please follow these steps to resolve common problems:

1. **Network Connectivity**: If you are experiencing issues connecting to the company's network or the internet, try the following steps:
   - Ensure your VPN connection is established and functioning correctly.
   - Check your network cable connections and try restarting your workstation.
   - If the issue persists, contact the IT helpdesk for further assistance.

2. **Software-related Issues**: If you are having trouble with any of the installed software, such as Microsoft Office, Microsoft Teams, or Jira, try the following:
   - Ensure you are using the latest version of the software.
   - Check for any pending software updates and install them.
   - If the issue continues, contact the IT helpdesk and provide a detailed description of the problem.

3. **Hardware Malfunctions**: If your workstation is experiencing hardware-related issues, such as a malfunctioning keyboard, mouse, or monitor, please submit a request to the IT helpdesk. The IT team will assess the problem and provide a solution, which may include replacing the faulty hardware.

4. **Account-related Problems**: If you are experiencing issues with your user account, such as password resets or access problems, contact the IT helpdesk immediately. The IT team will assist you in resolving the issue and ensure your account is functioning properly.

Rewards Service API Documentation

Introduction
The Rewards Service is a GraphQL-based microservice that enables CRUD (Create, Read, Update, Delete) operations for managing rewards. This service is designed to provide a comprehensive and efficient way to handle the lifecycle of rewards, ensuring seamless integration with various applications and systems within the organization.

GraphQL Services
The Rewards Service provides the following GraphQL services:

1. **Create a Reward**
   - **Description:** This mutation creates a new reward in the system.
   - **Request:**
     ```graphql
     mutation CreateReward($input: CreateRewardInput!) {
       createReward(input: $input) {
         id
         name
         description
         points
         expirationDate
       }
     }
     ```
   - **Response (200 OK):**
     ```graphql
     {
       "data": {
         "createReward": {
           "id": "reward-1",
           "name": "Free Shipping",
           "description": "Receive free shipping on your next order",
           "points": 500,
           "expirationDate": "2024-12-31"
         }
       }
     }
     ```
   - **Errors:**
     - **400 Bad Request:** If the input data is invalid or missing required fields.
     - **403 Forbidden:** If the user does not have the necessary permissions to create a reward.
     - **500 Internal Server Error:** If there is an unexpected error during the reward creation process.

2. **Update a Reward**
   - **Description:** This mutation updates an existing reward in the system.
   - **Request:**
     ```graphql
     mutation UpdateReward($id: ID!, $input: UpdateRewardInput!) {
       updateReward(id: $id, input: $input) {
         id
         name
         description
         points
         expirationDate
       }
     }
     ```
   - **Response (200 OK):**
     ```graphql
     {
       "data": {
         "updateReward": {
           "id": "reward-1",
           "name": "Free Shipping (Updated)",
           "description": "Receive free shipping on your next order (Updated)",
           "points": 750,
           "expirationDate": "2025-06-30"
         }
       }
     }
     ```
   - **Errors:**
     - **400 Bad Request:** If the input data is invalid or missing required fields.
     - **404 Not Found:** If the specified reward does not exist.
     - **403 Forbidden:** If the user does not have the necessary permissions to update the reward.
     - **500 Internal Server Error:** If there is an unexpected error during the reward update process.

3. **List a Reward**
   - **Description:** This query retrieves a single reward based on the provided ID.
   - **Request:**
     ```graphql
     query GetReward($id: ID!) {
       reward(id: $id) {
         id
         name
         description
         points
         expirationDate
       }
     }
     ```
   - **Response (200 OK):**
     ```graphql
     {
       "data": {
         "reward": {
           "id": "reward-1",
           "name": "Free Shipping (Updated)",
           "description": "Receive free shipping on your next order (Updated)",
           "points": 750,
           "expirationDate": "2025-06-30"
         }
       }
     }
     ```
   - **Errors:**
     - **404 Not Found:** If the specified reward does not exist.
     - **500 Internal Server Error:** If there is an unexpected error during the reward retrieval process.

   - **Errors:**

5. **Delete a Reward**
   - **Description:** This mutation removes an existing reward from the system.
   - **Request:**
     ```graphql
     mutation DeleteReward($id: ID!) {
       deleteReward(id: $id) {
         id
       }
     }
     ```
   - **Response (200 OK):**
     ```graphql
     {
       "data": {
         "deleteReward": {
           "id": "reward-1"
         }
       }
     }
     ```
   - **Errors:**
     - **404 Not Found:** If the specified reward does not exist.
     - **403 Forbidden:** If the user does not have the necessary permissions to delete the reward.
     - **500 Internal Server Error:** If there is an unexpected error during the reward deletion process.

Rate Limit
The Rewards Service has a rate limit of 100 requests per minute per user. If the rate limit is exceeded, the server will respond with a 429 Too Many Requests status code.

Error Handling
The Rewards Service follows a standard error handling approach, where errors are returned as part of the GraphQL response. The errors object in the response will contain information about the error, including the error code, message, and any additional context. The specific error codes used are:

- **400 Bad Request:** Indicates that the input data is invalid or missing required fields.
- **403 Forbidden:** Indicates that the user does not have the necessary permissions to perform the requested operation.
- **404 Not Found:** Indicates that the specified resource (e.g., a reward) does not exist.
- **429 Too Many Requests:** Indicates that the rate limit has been exceeded.
- **500 Internal Server Error:** Indicates an unexpected error occurred during the processing of the request.

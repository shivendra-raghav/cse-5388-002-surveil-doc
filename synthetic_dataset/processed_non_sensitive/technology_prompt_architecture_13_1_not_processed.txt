## GCP Architecture Documentation

### Introduction

Google Cloud Platform (GCP) is a comprehensive suite of cloud computing services provided by Google. It offers a wide range of solutions for businesses and individuals, including compute, storage, networking, and data management services. This documentation focuses on two key GCP services: SQL DB and Cloud Storage.

### Service Details

#### SQL DB

Google Cloud SQL is a fully-managed database service that allows you to set up, maintain, manage, and administer your relational databases on Google Cloud. It provides a seamless experience for deploying, managing, and scaling your databases, whether you're using MySQL, PostgreSQL, or SQL Server.

##### Key Features:
- **Automatic Upgrades and Patches**: Google Cloud SQL automatically applies security patches and upgrades to your database, ensuring that your system is always up-to-date and secure.
- **High Availability**: Cloud SQL provides built-in high availability, with automatic failover to a standby replica in the event of a failure.
- **Scalability**: You can easily scale your database up or down based on your changing needs, without any downtime.
- **Backup and Recovery**: Cloud SQL provides automated daily backups and the ability to restore your database to any point-in-time within the last seven days.
- **Replication**: Cloud SQL supports read replicas, allowing you to scale out your read workload and improve the performance of your applications.
- **Security**: Cloud SQL provides SSL/TLS encryption, IP whitelisting, and Identity and Access Management (IAM) integration for secure access to your databases.

##### Use Cases:
- **Web and Mobile Applications**: Cloud SQL is an excellent choice for hosting the databases that power your web and mobile applications, providing a reliable and scalable database solution.
- **Enterprise Applications**: Cloud SQL is suitable for hosting the databases that support your mission-critical enterprise applications, ensuring high availability and easy scalability.
- **Data Analytics**: Cloud SQL can be used as a data source for your data analytics and business intelligence workloads, providing a secure and managed database infrastructure.

##### Pricing and Availability:
Cloud SQL is available in all Google Cloud regions and offers a range of pricing options, including on-demand and committed-use discounts. Pricing is based on the instance type, storage, and data transfer used.

#### Cloud Storage

Google Cloud Storage is a fully-managed object storage service, providing durable and highly available storage for your data. It offers a range of storage classes to suit different use cases and data access patterns.

##### Key Features:
- **Durability and Availability**: Cloud Storage provides 99.999999999% (11 9's) of object durability and high availability, ensuring the safety and accessibility of your data.
- **Scalability**: Cloud Storage can automatically scale to accommodate your growing storage needs, without any need for manual intervention.
- **Performance**: Cloud Storage offers low-latency performance, ensuring fast data access and transfer speeds for your applications.
- **Security**: Cloud Storage provides encryption at rest, access control, and integration with Identity and Access Management (IAM) for secure data storage and access.
- **Data Lifecycle Management**: Cloud Storage supports lifecycle management policies, allowing you to automatically archive or delete data based on your retention requirements.

##### Use Cases:
- **Backup and Archiving**: Cloud Storage is an ideal solution for backup and archiving of data, providing durable and cost-effective storage for your critical files and data.
- **Media Hosting and Delivery**: Cloud Storage can be used to host and deliver large media files, such as videos, images, and audio, with high performance and reliability.
- **Big Data and Analytics**: Cloud Storage can serve as a scalable and cost-effective storage solution for your big data and analytics workloads, integrating seamlessly with various data processing and analytics tools.
- **Static Website Hosting**: Cloud Storage can be used to host the static content of your website, such as HTML, CSS, and JavaScript files, providing a simple and reliable hosting solution.

##### Pricing and Availability:
Cloud Storage is available in all Google Cloud regions and offers a range of storage classes with different pricing and performance characteristics. Pricing is based on the storage class, storage volume, and data transfer.

## GraphQL Services

The Feedback Service exposes the following GraphQL services:

### Create Feedback

**Description:**
This mutation allows you to create a new feedback record.

**Input Parameters:**
- `title`: string (required)
- `description`: string (required)
- `rating`: integer (required, range: 1-5)
- `userId`: string (required)

**HTTP Response Codes:**
- `200 OK`: The feedback was successfully created.
- `400 Bad Request`: One or more input parameters are invalid.
- `500 Internal Server Error`: An unexpected error occurred while processing the request.

**Example Query:**
```graphql
mutation CreateFeedback($input: CreateFeedbackInput!) {
  createFeedback(input: $input) {
    id
    title
    description
    rating
    userId
    createdAt
    updatedAt
  }
}
```

**Example Variables:**
```json
{
  "input": {
    "title": "Great product!",
    "description": "I really enjoyed using this product. It exceeded my expectations.",
    "rating": 5,
    "userId": "user123"
  }
}
```

**Example Response:**
```json
{
  "data": {
    "createFeedback": {
      "id": "feedback123",
      "title": "Great product!",
      "description": "I really enjoyed using this product. It exceeded my expectations.",
      "rating": 5,
      "userId": "user123",
      "createdAt": "2023-01-01T12:00:00Z",
      "updatedAt": "2023-01-01T12:00:00Z"
    }
  }
}
```

**Input Parameters:**

```graphql
mutation UpdateFeedback($input: UpdateFeedbackInput!) {
  updateFeedback(input: $input) {

    description
    rating
    userId
    createdAt
    updatedAt

}
```

### List Feedback

**Description:**
This query allows you to retrieve a list of feedback records based on the provided filters.

**Input Parameters:**
- `userId`: string (optional)
- `rating`: integer (optional, range: 1-5)
- `limit`: integer (optional, default: 10, max: 50)
- `offset`: integer (optional, default: 0)

**HTTP Response Codes:**
- `200 OK`: The feedback records were successfully retrieved.
- `400 Bad Request`: One or more input parameters are invalid.
- `500 Internal Server Error`: An unexpected error occurred while processing the request.

**Example Query:**
```graphql
query ListFeedback($input: ListFeedbackInput!) {
  listFeedback(input: $input) {
    items {
      id
      title
      description
      rating
      userId
      createdAt
      updatedAt
    }
    totalCount
  }
}
```

**Example Variables:**
```json
{
  "input": {

    "limit": 20,
    "offset": 0
```

**Input Parameters:**

## Rate Limit

The Feedback Service API is subject to a rate limit of 100 requests per minute per user. If you exceed this limit, you will receive a `403 Forbidden` response with the following error message:

```json
{
  "errors": [
    {
      "message": "Rate limit exceeded. Please try again later.",
      "extensions": {
        "code": "RATE_LIMIT_EXCEEDED"
      }
    }
  ]
}
```

## Error Handling

In addition to the rate limit error, the Feedback Service API may also return the following error responses:

**400 Bad Request**
- Returned when one or more input parameters are invalid or missing.
- Example error message: `"Invalid rating value. Rating must be between 1 and 5."`

**404 Not Found**
- Returned when the requested resource (e.g., a feedback record) is not found.
- Example error message: `"Feedback record with ID 'feedback123' not found."`

**500 Internal Server Error**
- Returned when an unexpected error occurs while processing the request.
- Example error message: `"An unexpected error occurred while processing the request."`

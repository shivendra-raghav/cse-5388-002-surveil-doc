## Backup Details

Azure SQL Database provides robust backup and recovery capabilities to help you protect your data and ensure business continuity in the event of a disaster or data loss.

### Automated Backups

Azure SQL Database automatically creates full, differential, and transaction log backups on a regular schedule, without the need for manual intervention. These backups are stored in geo-redundant Azure Blob storage, ensuring that your data is protected even in the event of a regional outage.

The default backup retention period for Azure SQL Database is 7 days, but you can configure this to be as long as 35 days. This provides you with the ability to quickly restore your database to a specific point in time, should the need arise.

### Manual Backups

In addition to the automated backups, you can also create manual backups of your Azure SQL Database at any time. This can be useful for scenarios where you need to create a backup before making major changes to your database, or for archiving purposes.

To create a manual backup, you can use the Azure portal, the Azure CLI, or PowerShell. The backup process will create a full backup of your database, which can then be used to restore the database to a specific point in time.

### Restore from Backups

If you need to restore your Azure SQL Database from a backup, you can do so using the Azure portal, the Azure CLI, or PowerShell. The restore process allows you to select a specific backup to restore from, and to choose the point in time to which you want to restore the database.

During the restore process, Azure SQL Database will create a new database with the restored data, ensuring that your production database remains unaffected. You can then migrate your applications and services to the restored database as needed.

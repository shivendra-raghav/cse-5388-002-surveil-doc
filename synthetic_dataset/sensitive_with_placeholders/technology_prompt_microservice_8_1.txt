## API Endpoints

### Authentication

The Discount Service API requires basic authentication for all endpoints. You must include an `Authorization` header with a base64-encoded `<USERNAME>` and `<PASSWORD>` in the following format:

```
Authorization: Basic <base64-encoded-username:password>
```

For example:

```
Authorization: Basic QWxhZGRpbjpvcGVuU2VzYW1l
```

**Note:** Replace `<USERNAME>` and `<PASSWORD>` with your actual credentials.

### Create a Discount

- **Endpoint:** `POST /v1/discounts`
- **Description:** Creates a new discount.
- **Request Body:**
  ```json
  {
    "name": "Summer Sale",
    "description": "20% off on all products",
    "discountPercentage": 20,
    "startDate": "2023-06-01",
    "endDate": "2023-08-31"
  }
  ```
- **Successful Response (200 OK):**
  ```json
  {
    "id": "1234567890",
    "name": "Summer Sale",
    "description": "20% off on all products",
    "discountPercentage": 20,
    "startDate": "2023-06-01",
    "endDate": "2023-08-31"
  }
  ```
- **Error Responses:**
  - `400 Bad Request`: Invalid request body.
  - `401 Unauthorized`: Missing or invalid authentication credentials.
  - `500 Internal Server Error`: An unexpected error occurred on the server.

### Update a Discount

- **Endpoint:** `POST /v1/discounts/:id`
- **Description:** Updates an existing discount by its ID.
- **Request Body:**
  ```json
  {
    "name": "Summer Sale",
    "description": "25% off on all products",
    "discountPercentage": 25,
    "startDate": "2023-06-01",
    "endDate": "2023-08-31"
  }
  ```
- **Successful Response (200 OK):**
  ```json
  {
    "id": "1234567890",
    "name": "Summer Sale",
    "description": "25% off on all products",
    "discountPercentage": 25,
    "startDate": "2023-06-01",
    "endDate": "2023-08-31"
  }
  ```
- **Error Responses:**
  - `400 Bad Request`: Invalid request body or discount ID.
  - `401 Unauthorized`: Missing or invalid authentication credentials.
  - `403 Forbidden`: Insufficient permissions to update the discount.
  - `404 Not Found`: The specified discount ID was not found.
  - `500 Internal Server Error`: An unexpected error occurred on the server.

### List a Discount

- **Endpoint:** `GET /v1/discounts/:id`
- **Description:** Retrieves a discount by its ID.
- **Successful Response (200 OK):**
  ```json
  {
    "id": "1234567890",
    "name": "Summer Sale",
    "description": "25% off on all products",
    "discountPercentage": 25,
    "startDate": "2023-06-01",
    "endDate": "2023-08-31"
  }
  ```
- **Error Responses:**
  - `401 Unauthorized`: Missing or invalid authentication credentials.
  - `403 Forbidden`: Insufficient permissions to access the discount.
  - `404 Not Found`: The specified discount ID was not found.
  - `500 Internal Server Error`: An unexpected error occurred on the server.

### Delete a Discount

- **Endpoint:** `DELETE /v1/discounts/:id`
- **Description:** Deletes a discount by its ID.
- **Successful Response (200 OK):**
  ```json
  {
    "message": "Discount deleted successfully"
  }
  ```
- **Error Responses:**
  - `401 Unauthorized`: Missing or invalid authentication credentials.
  - `403 Forbidden`: Insufficient permissions to delete the discount.
  - `404 Not Found`: The specified discount ID was not found.
  - `500 Internal Server Error`: An unexpected error occurred on the server.

## Rate Limit

The Discount Service API has a rate limit of 100 requests per minute per client. If the rate limit is exceeded, the server will respond with a `429 Too Many Requests` error and a `Retry-After` header indicating the number of seconds to wait before retrying.

## Error Handling

The Discount Service API uses standard HTTP response codes to indicate the success or failure of an operation. The following error codes may be returned:

- `400 Bad Request`: The request was malformed or missing required parameters.
- `401 Unauthorized`: The request did not include valid authentication credentials.
- `403 Forbidden`: The client does not have permission to access the requested resource.
- `404 Not Found`: The requested resource was not found on the server.
- `500 Internal Server Error`: An unexpected error occurred on the server.
- `501 Not Implemented`: The requested functionality is not implemented by the server.
- `502 Bad Gateway`: The server received an invalid response from an upstream server.
- `503 Service Unavailable`: The server is currently unavailable due to maintenance or overload.
- `504 Gateway Timeout`: The server did not receive a timely response from an upstream server.

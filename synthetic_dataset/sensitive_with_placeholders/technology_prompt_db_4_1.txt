On-demand backups allow you to create a full backup of your DynamoDb table data at any given time. These backups are stored in Amazon S3 and can be used to restore your table to a specific point in time. To create an on-demand backup, follow these steps:

Point-in-time Recovery (PITR):
Point-in-time recovery (PITR) is a continuous backup feature that automatically captures changes to your DynamoDb table data. With PITR enabled, you can restore your table to any point in time within the specified retention period. To enable PITR for your DynamoDb table, follow these steps:

1. In the AWS Management Console, navigate to the DynamoDb service.
2. Select the table for which you want to enable PITR.
3. Click on the "Backups" tab and then click on the "Point-in-time recovery" button.
4. Configure the desired backup retention period and click "Enable" to enable PITR for the selected table.

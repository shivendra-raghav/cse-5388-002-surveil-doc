GraphQL Services:

1. Create a Review:
   Description: This GraphQL mutation allows users to create a new review.
   Mutation: createReview(input: CreateReviewInput!): Review!
   Input: CreateReviewInput (productId: ID!, rating: Float!, comment: String!)
   Response Codes:
     - 200 OK: Review created successfully.
     - 400 Bad Request: Invalid input data.
     - 401 Unauthorized: Authentication failed.
     - 403 Forbidden: User does not have permission to create a review.

2. Update a Review:
   Description: This GraphQL mutation allows users to update an existing review.
   Mutation: updateReview(input: UpdateReviewInput!): Review!
   Input: UpdateReviewInput (id: ID!, rating: Float, comment: String)
   Response Codes:
     - 200 OK: Review updated successfully.
     - 400 Bad Request: Invalid input data.
     - 401 Unauthorized: Authentication failed.
     - 403 Forbidden: User does not have permission to update the review.
     - 404 Not Found: Review not found.

3. List a Review:
   Description: This GraphQL query retrieves a specific review by its ID.
   Query: review(id: ID!): Review
   Response Codes:
     - 200 OK: Review retrieved successfully.
     - 401 Unauthorized: Authentication failed.
     - 404 Not Found: Review not found.

4. List All Reviews:
   Description: This GraphQL query retrieves all reviews.
   Query: reviews(filters: ReviewFilters): [Review!]!
   Input: ReviewFilters (productId: ID, rating: Float, sortBy: ReviewSortBy)
   Response Codes:
     - 200 OK: Reviews retrieved successfully.
     - 401 Unauthorized: Authentication failed.

5. Delete a Review:
   Description: This GraphQL mutation deletes an existing review.
   Mutation: deleteReview(id: ID!): Boolean!
   Response Codes:
     - 200 OK: Review deleted successfully.
     - 401 Unauthorized: Authentication failed.
     - 403 Forbidden: User does not have permission to delete the review.
     - 404 Not Found: Review not found.
